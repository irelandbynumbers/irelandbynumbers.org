# irelandbynumbers.org

Redirects every irelandbynumbers.org address to the same page on [irelandbynumbers.ie](https://irelandbynumbers.ie).

GitHub Pages serves `index.html` for the home page and `404.html` for every other path, and both forward to irelandbynumbers.ie with the path, query and anchor kept. The site's own source is in [irelandbynumbers/irelandbynumbers.ie](https://github.com/irelandbynumbers/irelandbynumbers.ie).

DNS for irelandbynumbers.org: four A records for `@` pointing to 185.199.108.153, 185.199.109.153, 185.199.110.153 and 185.199.111.153, and a CNAME for `www` pointing to irelandbynumbers.github.io.
